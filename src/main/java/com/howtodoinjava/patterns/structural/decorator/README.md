# Decorator report example

Run from the repository root:

```bash
javac -d out src/main/java/com/howtodoinjava/patterns/structural/decorator/DecoratorDemo.java
java -cp out com.howtodoinjava.patterns.structural.decorator.DecoratorDemo
```

The example compares an original report with two decorated versions and shows that changing the nesting order changes which text is uppercased.
