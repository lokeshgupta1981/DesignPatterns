# Composite pattern: nested portfolio balances

From the repository root:

```bash
javac -d target/composite-demo -sourcepath src/main/java src/main/java/com/howtodoinjava/patterns/structural/composite/CompositeDemo.java
java -cp target/composite-demo com.howtodoinjava.patterns.structural.composite.CompositeDemo
```

The demo prints balances in whole cents. It also shows that repeated membership counts twice and that checked addition rejects overflow.
