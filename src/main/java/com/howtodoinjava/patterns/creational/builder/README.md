# Builder pattern example

Source code for the article https://howtodoinjava.com/design-patterns/creational/builder-pattern-in-java/

Run from the repository root:

```bash
javac -d out src/main/java/com/howtodoinjava/patterns/creational/builder/*.java
java -cp out com.howtodoinjava.patterns.creational.builder.BuilderDemo
```

The example uses only the JDK. The program builds two users and reports two rejected values.
