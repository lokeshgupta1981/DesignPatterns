# Simple Factory example

From the repository root:

```bash
javac -d out src/main/java/com/howtodoinjava/patterns/creative/factory/FactoryDemo.java
java -cp out com.howtodoinjava.patterns.creative.factory.FactoryDemo
```

This is a central, switch-based simple factory. The GoF Factory Method uses an overridable creation method in a creator hierarchy.
